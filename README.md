### Proyecto colaborativo

Participación en el desarrollo de un proyecto junto a otros colaboradores.

-Enlace para el proyecto de Github: https://github.com/MoisesSM-tech/Proyecto?utm_source=chatgpt.com

- Nombre de la aplicación: GDC
- Descripción: Es un gestor de comandas para un restaurante, con el objetivo de agilizar el proceso de toma y llegada de comandas a la cocina.
- En este se pueden crear, modificar y eliminar comandas, también se puede gestionar la producción de los platos de cada comanda, y modificar los platos que se encuentran disponibles en el momento de crear una comanda. Se pueden hacer borradores de comandas y puedes ver en cada momento las comandas que hay en producción y el estado de preparación en el que se encuentra cada una.
- Principalmente hemos usado Android Studio y programado con Kotlin, y como base de datos en la nube hemos usado Supabase.
